# اختبارات الشخصية – ما نوع شخصيتك؟

## وصف المشروع
موقع ويب تفاعلي للكشف عن نوع الشخصية، يعمل كصفحة واحدة (SPA) كاملة بدون أي إطار عمل.

## هيكل الملفات
```
personality-quiz/
├── index.html      ← الصفحة الرئيسية (HTML + SEO)
├── style.css       ← كامل التصميم (RTL + Dark Mode + Responsive)
├── script.js       ← المنطق الكامل + البيانات + الأصوات
├── assets/
│   ├── images/     ← مكان الصور التوضيحية
│   ├── icons/      ← أيقونات إضافية
│   └── fonts/      ← خطوط مُحمَّلة محلياً
└── README.md       ← هذا الملف
```

## طريقة التشغيل
افتح ملف `index.html` مباشرة في المتصفح – لا يحتاج إلى سيرفر.
